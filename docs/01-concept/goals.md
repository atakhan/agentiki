# Цели

## Текущие цели (подтверждаются кодовой базой)

1. **Детерминированное ядро симуляции** — тик с одновременным движением, едой, (опционально) взаимодействиями/встречами и выплатами PD.
2. **Стабильный контракт движка** — FastAPI говорит только с `SimulationEngine`; бэкенд выбирается через `AGENTIKI_SIM_BACKEND`.
3. **Браузерная визуализация** — pan/zoom canvas, отрисовка агентов и еды, debug-оверлей зрения/взаимодействия.
4. **HTTP control plane** — просмотр мира/ячеек/агентов/еды, step/reset, генерация популяции, observation.
5. **Общий хеш ячеек** — Python и TypeScript используют один u32-алгоритм, чтобы клиентская сетка совпадала с seed симуляции.

## В области сейчас

* Конечное seed-поле W×H с жёстким краем.
* Популяция агентов на сетке (generate / list / viewport query).
* Еда: capacity, seek, отдельный `EatAction`, shared energy, replenish.
* Движение с hash-жеребьёвкой конфликтов.
* Восприятие агентов и еды в настраиваемых радиусах.
* Встречи + PD (код есть; по умолчанию `enable_pd=False`).
* Временная стратегия: eat → seek food → random move.
* Запуск одной командой через Docker; локальная разработка в два процесса.

## Вне области сейчас

* Отбор, размножение, мутации и стартовое распределение генов (**Fact:** ядро трёх шкал умеет оценить оппонента, но тик его не вызывает; см. [genetics](../02-domain/genetics.md)).
* Трата `energy` / голод / влияние energy на решения.
* Незаглушенные биомы и влияние рельефа.
* Снимок запущенного мира (тик, агенты, встречи). Сохраняются только конфиги спавна, JSON в `data/world_configs/`.
* Аутентифицированное мультипользовательское управление.
* Модуль симуляции на Rust (только заглушка в factory).
* Автоматические CI-пайплайны (**Fact:** в репозитории нет `.github` workflows).

## Практические критерии успеха

Разработчик может:

1. поднять стек (Docker или локально);
2. сгенерировать агентов и еду и продвинуть мир;
3. видеть агентов, еду и (при включённом PD) встречи в UI;
4. запустить тесты: `uv run python -m unittest discover -s tests`;
5. найти, где менять конкретную механику (движение, еда, взаимодействие, встреча, PD, восприятие), не читая всё дерево.
