# Исследовательские вопросы

Открытые вопросы, к которым проект, судя по устройству, готовится. Уровень уверенности указан явно.

## Актуальные / ближайшие

| Вопрос | Статус | Заметки |
| --- | --- | --- |
| Как разрешать конфликты одновременного движения на плотной сетке? | Частично отвечен | Побеждает минимальный `agent_id`; цепочки и блокировки stay покрыты тестами. |
| Как в одном тике сочетаются контакт и движение? | Частично отвечен | Контакты по позициям на начало тика; цель может уехать в том же тике (есть тесты). |
| Какое локальное observation должна получать стратегия? | Открытый дизайн | `Observation.for_strategy()` скрывает id; временная стратегия всё ещё использует id. |
| Как итерированные PD-встречи сочетаются со свободой перемещения? | Частично отвечен | Участники активной встречи не выбирают world-действия и стоят на следующих тиках. |

## Методологические ограничения

* Предпочитать детерминированные seed, чтобы эксперименты воспроизводились.
* Держать API движка стабильным, чтобы менять бэкенд без переписывания UI.
* Отделять наблюдаемые результаты от интерпретации (см. `docs/06-experiments/`).
