# Видение

## Что это за проект

**agentiki** — платформа браузерной симуляции эволюции: бесконечное двумерное клеточное поле, детерминированное ядро с дискретными тиками и слой управления/визуализации (FastAPI + React Canvas).

**Fact** (из `README.md`, `pyproject.toml`): проект описан как browser evolution simulation с FastAPI в роли control plane и Python-ядром симуляции.

## Зачем он существует

Проект даёт площадку, чтобы запускать, наблюдать и развивать многоагентную пространственную симуляцию: агенты ходят по общей сетке, воспринимают соседей, инициируют контакты и во время встреч играют итеративную «дилемму заключённого» (Prisoner's Dilemma).

**Inference:** долгосрочное направление — эволюционная динамика агентов (название в README; неиспользуемое поле `genome`; планы на «тысячи агентов»). Сама эволюция как замкнутый цикл пока не реализована.

## Основная идея

1. Мир **бесконечен** и **детерминирован по seed**: ячейка `(x, y)` при данном seed всегда одна и та же.
2. Время идёт дискретными **тиками**. Внутри тика агенты действуют одновременно; конфликты разрешаются явными правилами.
3. У агентов есть **локальное восприятие** (радиусы зрения/взаимодействия по Чебышёву), они могут **двигаться** или **взаимодействовать**, а успешные контакты открывают **встречи** с раундами PD и накоплением **score**.
4. Ядро симуляции скрыто за стабильным контрактом **`SimulationEngine`**, чтобы Python-реализацию позже заменить на Rust/pyo3 без смены контракта API и UI.

## Какую проблему решает

Для пространственных многоагентных игр обычно нужен тяжёлый игровой движок или набор разовых скриптов. agentiki разделяет:

* заменяемое ядро симуляции;
* HTTP API управления;
* браузерный визуализатор с той же семантикой хеша ячеек, что и на сервере.

## Предположения

* Дискретная сетка; в ячейке не больше одного агента.
* Порядок тика и seeding RNG делают прогоны воспроизводимыми при данном seed и стратегии.
* UI — клиент API, а не второй источник истины по состоянию симуляции.
* Камера и отрисовка живут на клиенте; сервер владеет seed мира, тиком, агентами и механикой.

## Явные не-цели (текущий объём)

**Fact / Inference из кода и README:**

* Не общий игровой движок.
* Не сетевой мультиплеер.
* Не production-фреймворк для ML-обучения.
* Биомы/рельеф — заглушки (у каждой ячейки `"cell"` и один серый цвет).
* Полный эволюционный цикл (отбор, размножение, мутации геномов) не реализован.
* Rust-бэкенд запланирован, но в репозитории не установлен и не реализован.
