# Решение: Стабильный протокол SimulationEngine со сменяемыми бэкендами

## Контекст

Симуляции позже может понадобиться более быстрое ядро без переписывания control plane и UI.

## Альтернативы

* По доступным материалам неизвестны (другие варианты в репозитории не описаны).

## Решение

Отдавать наружу только `SimulationEngine`; FastAPI использует его; `create_engine(backend=...)` — Python сейчас, Rust/pyo3 позже (`agentiki_sim_rust`).

## Причина

Сформулировано в `protocol.py` и README: контракт стабилен, чтобы Rust мог заменить `PythonEngine`.

## Последствия

* API и UI не зависят от бэкенда.
* Rust должен совпадать с поведением протокола, включая ожидания детерминизма.
* Пока модуля нет, `backend=rust` падает в runtime.

# Решение: Бесконечное seed-детерминированное поле; камера на клиенте

## Контекст

Нужна обозримая бесконечная карта без хранения конечной тайловой БД.

## Альтернативы

* Неизвестны.

## Решение

Ячейки вычисляются из `(seed, x, y)`. Общий u32-хеш в Python и TypeScript. Камера в браузере; сервер отдаёт конфиг мира и состояние агентов.

## Причина

Сформулировано в README.

## Последствия

* Алгоритмы хеша клиента и сервера должны совпадать.
* Нет серверного состояния камеры/viewport.
* Biome/color могут оставаться заглушками при уже существующей инфраструктуре хеша.

# Решение: Одновременный тик с явными правилами конфликтов

## Контекст

Многоагентному движению по сетке нужно однозначное одновременное обновление.

## Альтернативы

* Неизвестны (пошаговый ход, непрерывная физика и т.п. в репозитории не обсуждаются).

## Решение

Все свободные агенты решают, затем в одном тике разрешаются взаимодействия, встречи и ходы; конфликты за цель — минимальный agent id; цепочки занятости — рекурсивно.

## Причина

Причина конкретного правила min-id по материалам не установлена сверх «deterministic tick» в README — само правило подтверждается кодом и тестами.

## Последствия

* Меньшие id системно выигрывают споры.
* Поведение тестируемо и воспроизводимо по seed при фиксированной стратегии.

# Решение: Взаимодействия открывают встречи с Prisoner's Dilemma

## Контекст

Пространственным агентам нужна модель взаимодействия со score.

## Альтернативы

* Неизвестны.

## Решение

Разрешённые контакты создают парные встречи; каждый тик активной встречи — раунд PD с continue/leave; score накапливается из матрицы выплат.

## Причина

Причина решения не установлена по доступным материалам (доменный выбор виден в коде/тестах, без прозаического обоснования).

## Последствия

* Score есть без давления отбора, пока нет эволюции.
* В тике открытия участники могут разъехаться, если цель тоже ходила.

# Решение: Временная RandomTestStrategy не является механикой мира

## Контекст

Нужен runnable default, чтобы прогонять движение, interaction и PD.

## Альтернативы

* Неизвестны.

## Решение

Поставлять `RandomTestStrategy` с пометкой «Temporary test strategy — not part of world mechanics.»

## Причина

Явный docstring модуля.

## Последствия

* Наблюдаемое поведение популяции — не утверждение о целевых эволюционных стратегиях.
* Замена стратегии — ожидаемый следующий шаг для доменных экспериментов.

# Решение: Однородные stub-ячейки (biome/color)

## Контекст

Инфраструктура хеша уже есть для будущего разнообразия рельефа.

## Альтернативы

* Неизвестны.

## Решение

`cell_biome` всегда возвращает `"cell"`; `cell_color` всегда фиксированный серый RGB в обоих языках.

## Причина

Причина решения не установлена по доступным материалам (вероятно поэтапный scaffolding — **Inference**, не fact).

## Последствия

* Поле визуально плоское; хеш не используется для внешнего вида.
