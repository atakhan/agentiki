# Правила и инварианты

## Жёсткие инварианты

1. **Занятость:** после применения движения тика в клетке не больше одного агента.
2. **Исключительность встречи:** агент состоит не более чем в одной активной встрече.
3. **Порядок радиусов:** `interaction_radius ≤ vision_radius`; оба `≥ 0`.
4. **Порядок матрицы PD:** `temptation > reward > punishment > sucker`.
5. **Детерминированная идентичность ячейки:** одинаковые `(seed, x, y)` → одинаковый hash.
6. **Потолок популяции:** count генерации в `[1, 100_000]`.

## Поведенческие правила

1. World actions выбирают только **свободные** агенты.
2. Агенты в активной встрече на следующих тиках не двигаются (решение пропускается → stay).
3. Занятые агенты не могут быть инициаторами или целями новых взаимодействий.
4. Для контакта взаимное намерение не обязательно; достаточно одного валидного инициатора.
5. Взаимное намерение схлопывается в одно событие взаимодействия.
6. В конфликтах движения предпочитается **минимальный agent id**.
7. При конкуренции за interact фактически выигрывает более ранний/меньший id (см. механики).
8. Встреча кончается, если **хотя бы один** участник выбрал leave после раунда PD.
9. Score меняется только выплатами PD (других decay/energy в коде нет).
10. Reset обнуляет тик, агентов, встречи и last step result; опционально меняет seed.

## Причинно-следственные связи

```text
радиусы восприятия
    → допустимые цели interact
        → события взаимодействия
            → встречи
                → раунды PD
                    → изменение score
                    → continue/leave
                        → снова свободны → могут ходить/interact
```

Движение параллельно открытию контакта, но по намерениям, выбранным до разрешения контакта; сам контакт опирается на позиции до хода.

## Явные не-правила (не действуют / отсутствуют)

* Genome не влияет на решения.
* Biome не влияет на движение, зрение или выплаты.
* Score пока не ограничивает действия и не запускает размножение.
* Нет голода, энергии и срока жизни.
