# Сущности

## Мир

| Свойство | Смысл |
| --- | --- |
| Seed | Задаёт детерминированную идентичность ячеек |
| Tick | Текущее дискретное время |
| `map_width` / `map_height` | Границы `[0, W) × [0, H)` (дефолт 64×64) |
| Размер ячейки spatial-индекса | Технический параметр запросов соседей (отдаётся в API) |

Сам мир не хранит конечную карту ячеек; ячейки внутри bounds вычисляются по запросу.

## Ячейка

| Свойство | Смысл |
| --- | --- |
| Координаты `(x, y)` | Целочисленная позиция на сетке |
| Hash | Детерминированный u32 от seed + координат |
| Biome | Метка рельефа (сейчас всегда `"cell"`) |
| Color | RGB для отображения (сейчас единый серый) |

## Агент

| Свойство | Смысл |
| --- | --- |
| Id | Уникальный целочисленный идентификатор |
| Ячейка `(x, y)` | Занятая клетка |
| Смещение внутри ячейки | Нормализованная позиция (по умолчанию центр) |
| State | `FREE` или `IN_MEETING` |
| Meeting id | Активная встреча, если есть |
| Hp | Жизнь-таймер: при спавне random в `[start_hp_min, start_hp_max]`; каждый тик −`hp_tick`; не пополняется; при ≤ 0 — удаление |
| Energy | Ресурс действий (`float`, старт `start_energy`=100): −ход/stay/решения/раунд; +еда/PD; ≤ 0 → смерть |
| Genome | Опциональный набор шкал ШВГОП / ШПМ / ШЗ. Оценка оппонента описана в [genetics](genetics.md). Тик поле не читает; при генерации оно пустое |

**Инвариант:** один агент на ячейку.

Конфликты движения решает жеребьёвка `move_priority(seed, tick, dest, agent_id)` (max wins), а не «меньший id». Id входит в хэш лотереи; при редком равенстве hash побеждает больший id. В конкуренции за interact-цель по-прежнему выигрывает меньший id инициатора.

## Еда (Food)

| Свойство | Смысл |
| --- | --- |
| Id | Уникальный идентификатор порции |
| Ячейка `(x, y)` | Не больше одной порции на клетку |
| Energy | Номинал порции (`food_energy`, дефолт 10.0); при поедании делится между едоками |

Еда не занимает слот занятости агента и не блокирует ход. На карте поддерживается ровно `food_capacity` порций (восполнение после поедания).

## Observation

Относительный взгляд наблюдателя:

* список других агентов в радиусе зрения;
* список видимой еды в радиусе зрения;
* у каждой записи относительные `(dx, dy)` в клетках;
* внутреннее observation может содержать id; projection для стратегии может их скрывать.

## Действие (world action)

Выбирается один раз за тик свободным агентом (участник встречи может получить `EatAction` из пайплайна):

* **Move** — stay, north, south, east, west;
* **Eat** — указать `food_id` в `interaction_radius`; весь тик без хода;
* **Interact** — указать id цели в радиусе взаимодействия (при `enable_pd=False` сводится к stay).

## Interaction (событие контакта)

| Свойство | Смысл |
| --- | --- |
| Пара `(a, b)` | Упорядочена по возрастанию id |
| Initiators | Подмножество пары, кто намеревался контакт |
| Tick | Тик, в котором контакт разрешён |

## Встреча (Meeting)

| Свойство | Смысл |
| --- | --- |
| Meeting id | Уникальный идентификатор |
| Пара агентов | Ровно два участника |
| Round number | Номер текущего раунда PD (с 1) |
| Status | `ACTIVE` или `FINISHED` |
| Started tick | Тик начала встречи |

**Инвариант:** агент участвует не более чем в одной активной встрече.

## Раунд PD

| Свойство | Смысл |
| --- | --- |
| Choices | У каждого: cooperate или defect |
| Payoffs | Целые из матрицы выплат |
| Continue choices | У каждого: continue или leave |
| Finished flag | Встреча кончается, если не оба continue |

## Матрица выплат

Классический порядок дилеммы заключённого:

`temptation > reward > punishment > sucker`

Значения по умолчанию: temptation `5`, reward `3`, punishment `1`, sucker `0`.

## Запрос генерации популяции

| Параметр | Смысл |
| --- | --- |
| Count | Сколько агентов разместить (`1…100_000`, не больше площади карты) |
| Density | Шаг решётки до ближайшего соседа по оси, `1…10`. Дробное значение округляется: `clamp(round(density), 1, 10)` |
| Map width / height | Границы мира для этой генерации |
| Food capacity / density radius / energy | Правила еды; после агентов спавнится `food_capacity` порций |
| Origin | Центр решётки (по умолчанию центр карты) |
| Life | Диапазон стартовой жизни, `hp_tick`, стартовая energy, траты energy, приток PD → energy |

Генерация очищает предыдущую популяцию и ставит агентов на квадратную решётку с этим шагом, не больше одного на ячейку. Число столбцов — `ceil(sqrt(count))`, строк — `ceil(count / столбцов)`. Решётка центрирована на origin. Если решётка или еда не помещаются — ошибка.

Seed мира на координаты агентов не влияет: `AgentPopulation.generate` принимает seed и отбрасывает его. `PythonEngine` всё ещё считает `seed XOR (generation * 0x9E3779B9) XOR (tick << 16)` и увеличивает счётчик генерации, но расстановка от этого числа не зависит. Начальный спавн еды использует RNG движка.
