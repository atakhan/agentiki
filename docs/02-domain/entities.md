# Сущности

## Мир

| Свойство | Смысл |
| --- | --- |
| Seed | Задаёт детерминированную идентичность ячеек |
| Tick | Текущее дискретное время |
| Размер ячейки spatial-индекса | Технический параметр запросов соседей (отдаётся в API) |

Сам мир не хранит конечную карту ячеек; ячейки вычисляются по запросу.

## Ячейка

| Свойство | Смысл |
| --- | --- |
| Координаты `(x, y)` | Целочисленная позиция на сетке |
| Hash | Детерминированный u32 от seed + координат |
| Biome | Метка рельефа (сейчас всегда `"cell"`) |
| Color | RGB для отображения (сейчас единый серый) |

## Агент

| Свойство | Смысл |
| --- | --- |
| Id | Уникальный целочисленный идентификатор (меньший id выигрывает часть конфликтов) |
| Ячейка `(x, y)` | Занятая клетка |
| Смещение внутри ячейки | Нормализованная позиция (по умолчанию центр) |
| State | `FREE` или `IN_MEETING` |
| Meeting id | Активная встреча, если есть |
| Score | Накопленные выплаты PD |
| Genome | Опциональные bytes; механикой не читается |

**Инвариант:** один агент на ячейку.

## Observation

Относительный взгляд наблюдателя:

* список других агентов в радиусе зрения;
* у каждой записи относительные `(dx, dy)` в клетках;
* внутреннее observation может содержать id; projection для стратегии может их скрывать.

## Действие (world action)

Выбирается один раз за тик свободным агентом:

* **Move** — stay, north, south, east, west;
* **Interact** — указать id цели в радиусе взаимодействия.

## Interaction (событие контакта)

| Свойство | Смысл |
| --- | --- |
| Пара `(a, b)` | Упорядочена по возрастанию id |
| Initiators | Подмножество пары, кто намеревался контакт |
| Tick | Тик, в котором контакт разрешён |

## Встреча (Meeting)

| Свойство | Смысл |
| --- | --- |
| Meeting id | Уникальный идентификатор |
| Пара агентов | Ровно два участника |
| Round number | Номер текущего раунда PD (с 1) |
| Status | `ACTIVE` или `FINISHED` |
| Started tick | Тик начала встречи |

**Инвариант:** агент участвует не более чем в одной активной встрече.

## Раунд PD

| Свойство | Смысл |
| --- | --- |
| Choices | У каждого: cooperate или defect |
| Payoffs | Целые из матрицы выплат |
| Continue choices | У каждого: continue или leave |
| Finished flag | Встреча кончается, если не оба continue |

## Матрица выплат

Классический порядок дилеммы заключённого:

`temptation > reward > punishment > sucker`

Значения по умолчанию: temptation `5`, reward `3`, punishment `1`, sucker `0`.

## Запрос генерации популяции

| Параметр | Смысл |
| --- | --- |
| Count | Сколько агентов разместить |
| Density | Компактность к origin (выше → теснее) |
| Origin | Центр диска генерации (по умолчанию `(0, 0)`) |

Генерация очищает предыдущую популяцию и ставит агентов не больше одного на ячейку, предпочитая клетки ближе к origin (экспоненциальные веса).
