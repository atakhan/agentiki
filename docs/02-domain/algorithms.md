# Алгоритмы

## Хеш ячейки (общий Python / TypeScript)

Для целых `x`, `y`, `seed` (как unsigned 32-bit):

```text
h = seed
h = h + x * 0x9E3779B1
h = h XOR y
h = h + y * 0x85EBCA77
h = mix32(h)
```

`mix32` — фиксированный avalanche-mixer (`>>16`, умножение `0x7FEB352D`, `>>15`, умножение `0x846CA68B`, `>>16`), всегда с маской 32 бит.

Функции biome/color хеш игнорируют и возвращают константы.

## RNG тика

Seed RNG на тик:

```text
(seed XOR (tick * 0x9E3779B9)) AND 0xFFFFFFFF
```

Используется временной случайной стратегией (и любой стратегией, которая берёт RNG тика).

## Генерация популяции

1. Ограничить density до `[0.01, 10]`.
2. Наращивать радиус диска, пока в нём не будет ≥ `count` клеток вокруг origin:
   ```text
   radius ≈ ceil(sqrt(count / (π * density)))
   ```
   затем расширять при необходимости.
3. Вес кандидата:
   ```text
   exp(-hypot(cx - origin_x, cy - origin_y) * density)
   ```
4. Выборка без возвращения взвешенным выбором до `count` клеток.
5. Поставить по одному агенту на клетку с последовательными id с 1.
6. Сначала очистить прежнюю популяцию.

Seed генерации смешивает seed мира, счётчик генерации и тик:

```text
seed XOR (generation * 0x9E3779B9) XOR (tick << 16)
```

## Разрешение движения

Входы: карта занятости и для каждого агента `(from, to)`.

1. Для каждой цели с ходящими (`to ≠ from`) победитель = `min(id претендентов)`.
2. Для каждого агента успех рекурсивно:
   * stay → успех;
   * не победитель цели → провал;
   * цель пуста или это сам → успех;
   * жилец цели тоже целится в ту же клетку → провал;
   * иначе успех, если успешен ход жильца;
   * циклы зависимостей → провал.
3. Итог: `to` при успехе, иначе `from`.

## Разрешение взаимодействий

Входы: карта initiator → target; множество занятых; популяция; радиусы; тик.

1. Отфильтровать валидные рёбра (радиус + существование + не busy), отсортировать по id инициатора.
2. Сначала взаимные: уникальные неупорядоченные пары, оба свободны → событие с двумя initiators.
3. Оставшиеся односторонние: событие с одним initiator; оба помечены used.
4. Отсортировать события по `(agent_a, agent_b)`.

## Выплаты PD

| A \ B | Cooperate | Defect |
| --- | --- | --- |
| Cooperate | (R, R) | (S, T) |
| Defect | (T, S) | (P, P) |

По умолчанию: `T=5`, `R=3`, `P=1`, `S=0`. Ограничение: `T > R > P > S`.

## Пространственный запрос соседей (Чебышёв)

Опросить все spatial-корзины квадрата `[x±r] × [y±r]`, оставить сущности с расстоянием Чебышёва до ячейки наблюдателя `≤ r` (индекс популяции использует корзины размера 1, выровненные по клеткам).
