# Обзор домена

Этот раздел описывает **предметную модель**: мир, агенты, время, восприятие, контакт, встречи и выплаты — без привязки к классам Python/TypeScript.

## Мир

* **Бесконечная двумерная целочисленная сетка** ячеек.
* Ячейка задаётся координатами `(x, y)`.
* При фиксированном **seed мира** у каждой ячейки есть детерминированная идентичность (хеш). Biome и цвет сейчас — однородные заглушки.
* Границ мира нет.

## Время

* Время идёт дискретными **тиками** (`0, 1, 2, …`).
* **Step** продвигает один или несколько тиков.
* Внутри тика свободные агенты решают одновременно; затем контакты, движение и раунды встреч идут по фиксированному пайплайну (см. [mechanics](mechanics.md)).

## Агенты

* Агент занимает ровно одну ячейку.
* В ячейке не больше одного агента.
* У агента есть числовой **score** (накопленные выплаты PD).
* Агент либо **свободен**, либо **во встрече**.
* Может нести placeholder **genome**; на поведение пока не влияет.

## Восприятие и действие

* Каждый свободный агент видит других в **радиусе зрения** (расстояние Чебышёва).
* По observation выбирает либо **движение** (стороны света / stay), либо **взаимодействие** с целью в **радиусе взаимодействия**.
* Радиус взаимодействия не может превышать радиус зрения.

## Контакт и встречи

* Валидные намерения взаимодействия превращаются в **события взаимодействия** (контакты).
* Контакт может открыть **встречу** двух агентов.
* На встрече играются раунды **Prisoner's Dilemma**; после каждого раунда оба выбирают **продолжить** или **уйти**.
* Встреча заканчивается, если не оба продолжили. Score обновляется каждый раунд.

## Поверхность управления (доменный взгляд)

Внешний оператор может:

* смотреть параметры мира и ячейки;
* генерировать популяцию вокруг origin;
* продвигать или сбрасывать время;
* смотреть текущее observation агента.

Это операции управления, а не внутримировые действия агента.
