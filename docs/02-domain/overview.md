# Обзор домена

Этот раздел описывает **предметную модель**: мир, агенты, время, восприятие, контакт, встречи и выплаты — без привязки к классам Python/TypeScript.

## Мир

* **Бесконечная двумерная целочисленная сетка** ячеек.
* Ячейка задаётся координатами `(x, y)`.
* При фиксированном **seed мира** у каждой ячейки есть детерминированная идентичность (хеш). Biome и цвет сейчас — однородные заглушки.
* Границ мира нет.

## Время

* Время идёт дискретными **тиками** (`0, 1, 2, …`).
* **Step** продвигает один или несколько тиков.
* Внутри тика свободные агенты решают одновременно; затем контакты, движение и раунды встреч идут по фиксированному пайплайну (см. [mechanics](mechanics.md)).

## Агенты

* Агент занимает ровно одну ячейку.
* В ячейке не больше одного агента.
* У агента есть **hp** (жизнь): траты за действия и приток от выплат PD. Отдельного score нет.
* Агент либо **свободен**, либо **во встрече**.
* Может нести placeholder **genome**; на поведение пока не влияет.

## Восприятие и действие

* Каждый свободный агент видит других в **радиусе зрения** (расстояние Чебышёва).
* По observation выбирает либо **движение** (стороны света / stay), либо **взаимодействие** с целью в **радиусе взаимодействия**.
* Радиус взаимодействия не может превышать радиус зрения.

## Контакт и встречи

* Валидные намерения взаимодействия превращаются в **события взаимодействия** (контакты).
* Новая встреча начинается только если на начало тика агенты — соседи по Чебышёву (`interaction_radius`, по умолчанию 1, восемь клеток). Дистанция ≥ 2 встречу не открывает.
* Контакт может открыть **встречу** двух агентов. Дальше встреча не перепроверяет соседство: она продолжается, даже если в том же тике цель ушла. Пока встреча активна, участники не ходят.
* На встрече играются раунды **Prisoner's Dilemma**; после каждого раунда оба выбирают **продолжить** или **уйти**.
* Встреча заканчивается, если не оба продолжили, либо если участник умер (hp ≤ 0 в конце тика). Каждый сыгранный раунд меняет hp: сначала приток, затем стоимость раунда. Отдельного score нет.

## Поверхность управления (доменный взгляд)

В UI оператор:

* на главной выбирает «Новый мир» или «Загрузить мир»;
* на экране конфигурации задаёт число агентов, плотность `1…10` (шаг решётки) и правила жизни, затем «Старт» или «Сохранить конфиги»;
* «Загрузить мир» открывает тот же экран уже заполненным, не симуляцию;
* на симуляции включает play/pause, «Рестарт» (тот же конфиг, камера на месте, пауза, тик 0), масштаб и «Вид», возвращается назад и смотрит инспектор агента.

На экране симуляции нет меню числа агентов, плотности и «Жизнь». Ручных «Шаг» и «×10» нет. По HTTP по-прежнему доступны просмотр мира, генерация, step, reset и observation. Это операции управления, а не внутримировые действия агента.
