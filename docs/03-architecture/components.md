# Компоненты

## SimulationEngine (protocol)

* **Назначение:** стабильный контракт бэкендов.
* **Входы:** seed, число шагов, параметры генерации, запросы observation.
* **Выходы:** ячейки, агенты, результаты step (взаимодействия, встречи, раунды PD).
* **Зависимости:** ничего «сверху»; реализуется `PythonEngine` (и будущим Rust).

## PythonEngine

* **Назначение:** in-process Python-бэкенд.
* **Владеет:** seed/tick мира, `InfiniteWorld`, `AgentPopulation`, `MeetingStore`, экземпляром стратегии, последним `StepResult`.
* **Сотрудничает с:** модулями пайплайна `step_tick`.
* **Замечание:** отдаёт `spatial` / `spatial_cell_size`, но запросы восприятия идут через spatial-индекс популяции (см. `REVIEW.md`).

## InfiniteWorld

* **Назначение:** ячейки по запросу, детерминированно.
* **Вход:** координаты + seed.
* **Выход:** записи `Cell`.

## AgentPopulation

* **Назначение:** хранение агентов, карта занятости, spatial-индекс, генерация, атомарное применение позиций.
* **Инварианты:** уникальность занятости.

## Пайплайн тика (`step_tick`)

* **Назначение:** оркестрация одного тика: observe → decide → interact → meet → move → PD.
* **Зависит от:** протокола стратегии, популяции, config, meeting store, RNG.

## Подсистема движения

* **Назначение:** построение intents и разрешение одновременных ходов.
* **Ключевое правило:** победитель цели — min id + логика цепочек/зависимостей.

## Подсистема взаимодействий

* **Назначение:** превратить interact-намерения в события контакта.

## Подсистема встреч + PD

* **Назначение:** жизненный цикл встречи, выплаты, continue/leave, обновление score.

## Подсистема восприятия

* **Назначение:** строить observation; классифицировать interactable-смещения.

## Стратегия

* **Назначение:** observation (+ контекст встречи) → действия / PD / continue.
* **Сейчас:** только временная `RandomTestStrategy`.

## Приложение FastAPI

* **Назначение:** HTTP API + опциональный mount статики UI + CORS для origin Vite.
* **Lifecycle:** создаёт движок из env при старте.

## React-приложение

| Часть | Роль |
| --- | --- |
| `App` | Состояние мира/агентов, play loop, выделение, оверлеи |
| `TopBar` | Контролы: generate, step, play, zoom, density |
| `WorldCanvas` | Камера по указателю, цикл отрисовки |
| `api.ts` | Обёртки fetch |
| `world/*` | Хеш, рендереры сетки/агентов/зрения/взаимодействий, анимация |

## Контракты данных (модели API)

Pydantic-модели зеркалят доменные понятия в JSON (`WorldOut`, `AgentOut`, `StepOut`, observation, раунд PD и т.д.). TypeScript-типы фронта параллельны этим формам.
