Формальных воспроизводимых записей экспериментов в репозитории **пока нет**.

Эта папка — место для будущих протоколов. При добавлении используйте:

```text

Гипотеза:
Цель:
Параметры:
Окружение:
Процедура:
Наблюдаемые результаты:
Интерпретация:
Ограничения:
```

## Базовый прогоняемый сценарий (не опубликованный эксперимент)

Удобная отправная точка для будущих заметок:

| Поле | Значение |
| --- | --- |
| Цель | Визуально прогнать цепочку interaction → meeting → PD |
| Окружение | `docker compose up --build` или локальные uvicorn + Vite |
| Параметры | seed `1`, backend `python`, generate `count=100`, `density=1.0` |
| Процедура | Generate → Play → опционально выбрать агентов |
| Наблюдаемые результаты | *заполнить после прогона — не выдумывать* |
| Интерпретация | Отдельно от наблюдений |
| Ограничения | Стратегия — временная случайная; эволюции нет |

Не считать игровые сессии в UI научным результатом, пока не зафиксированы параметры, seed и процедура.
